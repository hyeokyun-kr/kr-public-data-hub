# KR Public Data Hub 사용설명서 (v0.4)

KOSIS(국가통계포털)와 한국은행 ECOS의 통계, 공공데이터포털(data.go.kr)의 파일·오픈API 목록, 그리고 금융감독원 전자공시(OpenDART)의 회사 재무제표·공시 목록을 한 화면에서 찾고, 미리 본 뒤 출처가 적힌 Excel·CSV로 받는 도구다. 이 컴퓨터에서만 열리고(주소 `127.0.0.1`), 수치는 받을 때마다 기관 API에서 새로 가져온다.

- 화면 맨 위 **통계 / 회사(DART) / 의결서 / AI 추천** 단추로 바꾼다. 통계는 3~5장, AI 추천은 4-3장, 회사는 6장, 의결서는 6-3장.

## 1. 켜기

- **Mac**: `run_mac.command`를 더블클릭 → 터미널 창에 "켜는 중"이 나오고, 서버가 응답하면 브라우저에 `http://127.0.0.1:8765`가 열린다(보통 몇 초). 처음 몇십 초는 화면에 "검색 색인 불러오는 중"이 보일 수 있다. **터미널 창을 닫으면 꺼진다.**
  - "확인되지 않은 개발자" 창이 뜨면: 파일을 오른쪽 클릭 → 열기.
  - 이미 켜져 있을 때 다시 더블클릭하면 브라우저만 연다.
  - 켜지지 않으면 터미널 창에 오류가 남고, 전체 기록은 `data/server.log`에 있다.
  - 느린 외장 디스크에 두면 처음 켤 때 색인 읽기에 몇 분 걸리기도 한다. 1분이 지나면 터미널에 "아직 켜는 중"이 나오고, 켜지면 브라우저가 저절로 열린다.
- **Windows**: `run_windows.bat` 더블클릭(파이썬 3.10 이상 필요).
- **터미널에서**: `python3 -m datahub.server` (포트 바꾸기: `--port 8770`)
- 처음 한 번은 필요한 패키지(fastapi, uvicorn, httpx, openpyxl)를 자동으로 설치한다.

## 2. API 키 넣기

- 키는 각자 기관에서 무료로 받는다(받는 곳은 `.env.example` 안에 적혀 있음). 저장소에는 키가 들어 있지 않다.
- `.env.example`을 복사해 `.env`로 이름을 바꾸고 `KOSIS_API_KEY`·`ECOS_API_KEY`·`OPENDART_API_KEY`·`DATA_GO_KR_SERVICE_KEY`(선택: `ANTHROPIC_API_KEY`·`OPENAI_API_KEY`)를 채운다. 환경변수로 넣어도 되고, 환경변수가 먼저다. `.env`는 `.gitignore`에 들어 있어 저장소에 올라가지 않는다.
- 없는 키의 기능만 꺼지고 나머지는 그대로 쓴다.
- 화면 오른쪽 위 점이 초록이면 키가 있는 것이다. 빨간 "키 없음"이면 위를 확인한다.

## 3. 찾기

- 검색창에 통계 이름, 영문 약어, 비슷한 말을 넣는다. 예: `CPI`, `원달러 환율`, `기업 규모`, `대형마트 매출`.
- **동의어도 함께 찾기**(기본 켜짐): `CPI` → 소비자물가지수, `PPI` → 생산자물가지수처럼 같은 말을 함께 찾는다.
  - 검색 결과 위에 "같은 뜻으로 함께 찾음"과 "관련 통계(정의가 다를 수 있음)"가 따로 나온다. 관련 통계는 이름이 비슷해도 기준연도·단위·조사 대상이 다를 수 있으니 상세 화면에서 정의를 꼭 확인한다.
- 결과 왼쪽 색 띠: **청록 = KOSIS**, **남보라 = ECOS**, **주황 = 공공데이터포털**. 꼬리표: 수록 기간(`2016–2026`), 수록 기간을 모르는 KOSIS 표는 최종 갱신 연도(`갱신 2025`), 마지막 연도가 3년 넘게 지난 표는 `마지막 자료 2021`(기간을 모르면 `마지막 갱신 2021`, 폐지됐다는 뜻은 아님 — 5년 주기 조사나 해마다 새 표로 나오는 지자체 조사일 수 있음), `지자체 통계`(KOSIS 지역통계), `국제·외국 통계`(IMF 등), 공공데이터포털은 `파일데이터 csv`·`수정 2025-12-04`.
- 결과 아래 회색 줄은 왜 찾았는지다(예: "동의어 '소비자물가지수' → 이름 일치", "항목 '원/미국달러(매매기준율)'"). ECOS는 통계표 안의 항목 이름까지 찾는다.
- 필터: 기관(KOSIS·ECOS·공공데이터포털), 주기(연·분기·월·일), "지금도 나오는 통계만"(공공데이터포털은 수정일이 3년 넘게 지난 목록을 뺀다).
  - 공공데이터포털 목록은 자료 주기 정보가 없어 주기 필터를 켜면 빠진다. 공공데이터포털 목록은 점수를 조금(5점) 낮춰, 비슷하게 맞으면 KOSIS·ECOS가 먼저 나온다(다만 마지막 자료가 오래된 통계는 그보다 더 내려가므로 늘 먼저인 것은 아님).
  - 이름 다음으로 키워드, 작성·제공 기관 이름(예: `관세청`), 설명 순으로 찾는다. 결과는 60개씩 보이고 맨 아래 **더 보기**로 이어 본다.
  - KOSIS 표 대부분은 색인에 주기 정보가 없어서, 주기 필터를 켜면 빼지 않고 `주기 확인 전(열면 확인)` 표시를 달아 아래쪽에 둔다. 한 번 열어 본 표는 실제 주기가 저장되어 다음부터 정확히 걸러진다.

## 4. 고르고 미리보기

1. 결과를 누르면 오른쪽에 작성 기관, 통계표 ID, 수록 주기·기간, 단위, 통계 설명, 원천 주석이 나온다. "원본 화면 열기"로 기관 사이트의 같은 표를 연다.
2. **조회 조건**: 주기를 고르고 시작·끝 시점을 넣는다(월 `2020-01`, 분기 `2020-Q1`, 연 `2020`, 일 `2020-01-01`). "최근 1년·5년·10년·전체" 단추도 있다.
3. 항목·분류(예: 시도별, 품목별)마다 필요한 것을 체크한다. 칸에 이름을 넣어 좁힐 수 있다. 처음에는 첫 항목(대개 총계·전국)이 골라져 있고, ECOS는 검색어에 맞은 항목이 골라져 있다.
4. **미리보기**를 누르면 그래프와 최근 36개 시점 표가 나온다. 아래 "출처·조회 조건 기록"에 실제로 부른 API 주소(인증키는 가림)가 있다.

## 4-2. 공공데이터포털 자료

- 공공데이터포털(data.go.kr)의 파일데이터·오픈API·표준데이터 목록 약 10만 3천 건을 함께 찾는다(포털이 매달 올리는 '목록개방현황' 기준). 결과에는 파일·API 구분, 형식(csv 등), 수정일이 붙는다.
- 결과를 누르면 제공기관, 분류, 형식, 수정일, 업데이트 주기, 행 수, 이용허락범위, 설명, 키워드가 나온다. KOSIS처럼 기간·항목을 골라 미리보는 칸은 없다.
- **파일 받기(원본 그대로)**: 포털에 올라간 파일이면 원본 파일을 그대로 받는다(내용을 바꾸지 않음, 포털에서 직접 받은 것과 바이트까지 같음). 포털이 보안 확인(캡차)을 요구하면 받지 않고 알려 주니, **원본 페이지 열기**로 포털에서 받는다.
- 기관 사이트에 있는 파일, 오픈API는 **원본 페이지 열기**만 된다. 오픈API는 포털에 로그인해 API마다 '활용신청'을 해야 쓸 수 있다.
- 파일마다 칸 구성이 제각각이라 출처 시트를 붙인 Excel로 바꾸지는 않는다. 받은 기록은 `data/download_log.csv`에 남는다.

## 4-3. AI 추천(문장으로 묻기)

- 화면 위 **AI 추천**을 누르고 필요한 자료를 문장으로 쓴다(예: `라면 시장이 커졌는지 볼 수 있는 자료`, `편의점 가맹점 수와 매출 추이`).
- AI가 질문을 검색어 몇 개로 풀고 → 이 프로그램 색인(KOSIS·ECOS·공공데이터포털)에서 후보를 모은 뒤 → **후보 안에서만** 볼 만한 순서로 고른다. 항목마다 추천 이유 한 줄과 '확인:' 주의점 한 줄이 붙는다. 누르면 평소 상세 화면으로 가니, 정의·단위·기간은 직접 확인한다.
- **숫자는 알려 주지 않는다.** 색인에 없는 자료를 지어내지 못하게, AI가 고른 번호가 후보 목록에 없으면 버린다.
- 왼쪽에는 추천 목록만, 오른쪽 위 **'AI 추천 설명'** 칸에 'AI가 이렇게 이해했습니다', **방향 제시**(이 질문을 어떤 관점으로 보면 좋은지, 그래서 무엇을 앞에 두었는지), 질문이 모호하면 '더 정확히 하려면' 되묻기, **'이 색인에 없는 자료·찾아볼 곳'**(이 프로그램의 회사(DART) 업종 비교·기업집단·의결서 화면, 한국석유공사 오피넷 같은 바깥 출처), 찾아본 검색어와 사용한 모델·시간·토큰·대략 비용이 나온다.
- 이 설명 칸은 목록에서 자료를 눌러도 그대로 위에 남고(상세는 그 아래), **접기/펼치기**로 줄일 수 있다. 좁은 화면에서는 목록 위에 나온다.
- **모델**(안내 줄의 칸에서 고름, 이 브라우저에 기억): 기본 **Claude Sonnet 5.5**(20초 안팎, 질문당 50원 안팎), **Claude Haiku 5.5**(더 빠르고 질문당 몇 원, 품질은 조금 낮음), **GPT-6.1 Sol**(Sonnet과 같은 가격대), **GPT-6.1 Terra**(GPT 쪽 가벼운 것). 가격(100만 토큰당 입력/출력): Sonnet 5.5 $2/$10, Haiku 5.5 $0.10/$0.50, GPT-6.1 Sol $2/$10, GPT-6.1 Terra $1/$5. 모델 목록·기본값은 `datahub/ai_recommend.py` 맨 위 `MODELS`·`DEFAULT_MODEL`에서 바꾼다(의결서 AI 질문은 따로: `datahub/decision_ai.py`의 `DEC_MODELS`·`DEC_DEFAULT`).
- **질문 문장과 후보 목록(이름·기관·분류·기간)이 고른 AI 회사(Anthropic 또는 OpenAI)로 나간다.** 밖으로 나가면 안 되는 정보는 넣지 않는다. 질문은 이 PC에 따로 기록하지 않는다.
- 키: Claude는 `ANTHROPIC_API_KEY`, GPT는 `OPENAI_API_KEY`(환경변수 또는 `.env`). 화면 오른쪽 위 'AI' 점이 초록이면 Claude 키가 있는 것이다.

## 5. 받기

- **Excel 받기**: 시트 3개 — `데이터(가로형)`(기본: 행=시점, 열=시계열. 재무제표는 행=계정, 열=연도. 아래 '행·열 배치'로 바꿀 수 있음), `데이터(세로형)`(한 줄=한 시계열의 한 시점, 코드 포함), `출처·조회조건`(원천 시스템, 작성 기관, 통계표 ID, 분류 경로, 원본 화면 주소, 주기·기간, 선택 항목, 수집 시점, API 호출 주소, 원천 주석).
- **CSV 받기**: 세로형(기본, 줄마다 출처·ID·코드·수집 시점이 붙음) 또는 가로형(화면 배치대로). Excel에서 한글이 깨지지 않게 UTF-8(BOM)으로 저장한다.
  - 가로형은 맨 위에 `#`로 시작하는 출처 줄(원천, 통계표 ID, 조회 기간, 선택, 수집 시점, 호출 주소)이 붙는다. 파이썬은 `pd.read_csv(파일, comment="#")`로 읽는다.
- **행·열 배치**(KOSIS의 행렬전환과 같음): 미리보기 표 위 '행·열 배치' 칸에서 분류(항목·시도·계정 등)와 시점을 행 또는 열로 보낸다.
  - **열로 → / ← 행으로**: 그 분류를 반대쪽으로 옮긴다. **↑**: 같은 쪽 안에서 바깥(앞)으로 옮긴다. **행↔열 통째로**: 행과 열을 맞바꾼다. **처음대로**: 기본 배치로 돌린다.
  - 미리보기 표가 바로 그 배치로 바뀌고, **Excel의 `데이터(가로형)` 시트·CSV 가로형·다운로드 목록(ZIP)**이 같은 배치로 받아진다. 세로형은 배치와 상관없이 그대로다. 출처 시트(CSV는 `#` 줄)에 '행·열 배치'가 적힌다.
  - 열에 분류를 둘 이상 두면 머리글이 여러 줄이 된다(화면은 같은 값을 한 칸으로 합쳐 보이고, 파일은 Excel 필터·피벗이 되게 칸마다 이름을 그대로 둔다).
  - 이름이 모든 분류에서 겹치는데 코드가 다른 시계열은 이름 뒤에 `(코드)`를, 시계열마다 단위가 다르면 첫 분류 이름 뒤에 `[단위]`를 붙여 칸이 섞이지 않게 한다.
  - 새로 미리보기를 하면 배치는 기본으로 돌아간다. 다운로드 목록에 담은 것은 담을 때의 배치를 기억한다.
- **다운로드 목록에 담기** → 아래 검은 막대의 **ZIP으로 모두 받기**: 담은 통계마다 Excel+CSV, 그리고 전체 목록 `00_출처_조회조건.csv`.
- 값은 기관 API가 준 그대로다(CSV는 문자 그대로, Excel은 숫자로 읽히는 값만 숫자 칸, 유효숫자 15자리를 넘는 수는 정밀도를 잃지 않게 글자 칸). 원천이 값을 비워 준 칸(null)은 빈칸으로 둔다. 단위 변환·시계열 이어 붙이기는 하지 않는다.
- 받은 기록은 `data/download_log.csv`에 쌓인다.

## 6. 회사(DART): 재무제표·공시 목록·업종 비교

1. 위쪽 **회사(DART)**를 누르고 회사 이름, 종목코드 6자리, 영문명으로 찾는다(예: `삼성전자`, `005930`, `LG전자`). '(주)'·'주식회사'는 없어도 된다. **상장사만**을 켜면 비상장사를 뺀다.
   - 회사 이름 검색은 이 PC 안의 회사 목록(OpenDART 고유번호 약 12만 개, 일주일마다 자동으로 새로 받음)에서만 한다. 금감원에는 고른 회사의 **고유번호 8자리와 연도·보고서 종류만** 간다. 검색어는 어디로도 가지 않는다.
2. 회사를 누르면 기업개황(고유번호, 종목코드, 시장, 대표자, 업종코드, 설립일, 결산월)이 나온다.
3. **재무제표** 탭
   - 범위: **주요계정**(기본, 자산·부채·자본총계, 매출액, 영업이익, 당기순이익 등 표준 계정 15개 안팎, 이름이 해마다 같아 연도 비교가 쉬움) 또는 **전체 계정**(회사가 낸 재무상태표·손익계산서·포괄손익계산서·현금흐름표·자본변동표 전부).
   - 구분: 연결 / 별도. 연결재무제표가 없는 회사(종속회사 없음)는 '별도'를 고른다.
   - 보고서: 사업보고서(연간) / 반기 / 1분기 / 3분기. 분기·반기는 손익을 **누적**(사업연도 시작부터, 12월 결산이면 1월부터) 또는 **해당 분기 3개월**로 고른다. 현금흐름표는 원천대로 누적이다.
   - 사업연도: 2015년부터, 한 번에 12개 연도까지. 아직 보고서가 없는 연도는 빼고 경고로 알려 준다.
   - 미리보기 표는 행 = 계정, 열 = 연도다. **화면 표시 단위**(원·백만원·억원)는 화면만 바꾸고, 파일은 원 단위 원천 값 그대로다.
4. **공시 목록** 탭: 기간을 넣고 미리보기 → 접수일자·보고서명·제출인·접수번호. 보고서명을 누르면 DART 원문이 열린다. 최신순 최대 2,000건.
5. **업종 비교** 탭: 그 회사의 업종코드(한국표준산업분류)를 세세분류 → 중분류 단계로 보여 주고, 고른 단계로 시작하는 **상장사 전체**의 매출액·영업이익·당기순이익·자산·부채·자본총계와 매출 비중을 한 표로 받는다.
   - 처음 한 번은 **상장사 업종코드 받기**가 필요하다(상장사 약 4천 곳의 기업개황, 15분 안팎). 다시 받을 때는 `python3 -m datahub.build_catalog --only dart-industry`.
   - 매출 비중은 이 표에 든 상장사 매출 합계 대비 비율로 프로그램이 계산한 값이다. 회사 전체 매출(해외·다른 사업 포함)이라 **관련시장 점유율이 아니다**. 비상장사·외국 회사는 빠져 있다.
   - 연결이 없는 회사는 별도 금액을 넣고 '재무제표' 칸에 적는다. 그해 주요계정이 없는 상장사도 빼지 않고 표 아래쪽에 '자료 없음'으로 둔다. 결산월이 다른 회사는 '손익 기간' 칸을 본다.
6. 받기·다운로드 목록·ZIP은 통계와 같다(5장). 재무제표 Excel은 `데이터(가로형)`(계정 × 연도, 천 단위 쉼표 표시), `데이터(세로형)`, `출처·조회조건`(연도별 접수번호와 원문 주소 포함) 세 시트다.

**재무제표를 읽을 때 알아 둘 것**

- 각 연도 값은 그 연도 보고서의 '당기' 금액이다. 뒤 연도 보고서에서 재작성(소급 수정)된 금액으로 바꾸지 않는다.
- 전체 계정은 회사가 낸 XBRL 그대로라 계정 이름·코드가 해마다 바뀐다. 같은 표에서 이름이 같으면(띄어쓰기·주석 번호·'(손실)'·'(결손금)'·'(*1)' 표시 무시, '(수익)'·'(비용)'은 구분) 한 줄로 잇고, 이름이 바뀐 경우는 그 표에 한 번만 나오는 같은 계정코드일 때만 잇는다(계정 칸에 '예전 이름'을 적음). 이 조건은 한 줄 안의 **모든 연도끼리** 맞아야 하며, 다른 해를 거쳐 잇지 않는다. 이을 수 없는 계정은 몇 해만 채워진 줄로 남는다. 연도 비교는 **주요계정**이 안전하다.
- 현금 유출 금액의 부호(-)를 해마다 다르게 적는 회사가 있다. 원천 값을 그대로 두므로, 부호가 바뀌면 원문 보고서로 확인한다.

## 6-2. 기업집단(공정위 기업집단포털)

- 공정위가 지정한 대규모기업집단(공시대상·상호출자제한)의 지정 현황, 소속회사, 계열 편입·제외·유예 변경내역을 본다. 공개년월(지정 기준 연월) 1997년부터 2026-05까지 29개를 색인에 받는다(2026-11-16 기준 지정 집단 102곳·소속회사 3,539곳·변경내역 4,665건).
- **회사(DART)에서 회사를 고르면** 기업개황에 **소속 기업집단**이 나온다(법인등록번호로 정확히 찾음). 지금은 소속이 아니면 '○○까지, 지금은 지정 소속 아님'으로 표시한다. **집단 보기**를 누르면 집단 화면으로 간다.
- **회사 검색창에 집단 이름**(예: `삼성`, `에스케이`)을 넣으면 결과 위에 '기업집단' 단추가 나온다. 대표회사 이름으로도 찾는다.
- 집단 화면: 동일인, 대표회사, 소속회사 수, 상호출자제한 여부, 자산총액(원천 단위 10억원을 조원으로 표시)·순위, 공개년월 고르기, 소속회사 목록(법인등록번호·대표자·설립일·계열편입일), 변경내역(일자·편입/제외/유예·사유).
  - 소속회사 이름을 누르면 회사(DART) 화면으로 간다. DART 연결은 법인등록번호가 같은 회사를 먼저 쓰고, 없으면 이름이 DART 회사 목록에 하나뿐일 때만 잇는다(동명 회사는 잇지 않음).
- 받기: 소속회사 / 변경내역 / 그해 전체 집단 목록을 Excel·CSV로(출처 시트에 기업집단포털·공개년월·색인 받은 시각).
- 색인 다시 받기: `python3 -m datahub.build_catalog --only egroup`(호출 약 130번, 몇 분). 매년 5월 지정 뒤와 변경내역이 필요할 때. 키는 `DATA_GO_KR_SERVICE_KEY`(공공데이터포털에서 기업집단포털 API 활용신청 필요).
- 아직 안 붙인 기업집단포털 API: 소속회사 개요·재무·주주·임원·참여업종, 순환출자, 내부지분, 지주회사(필요하면 추가).

## 6-3. 의결서(공정위 의결서 본문 검색)

- 공정위 사건처리시스템(case.ftc.go.kr)에 공개된 의결서 **20,323건**(1981~2026-10 의결, 본문 208,548쪽)을 **본문까지** 찾는다. 2026-11-13~16에 따로 모아 만든 색인 기준이다. **선택 기능**이며 색인(`data/decisions.sqlite`)은 이 저장소에 들어 있지 않다(README '의결서 탭').
- **검색은 이 프로그램 안 색인에서만** 한다. 검색어는 공정위든 어디든 밖으로 나가지 않는다. 원문 PDF를 열 때만 공정위 사이트에서 그 한 건을 받는다(받아 둔 PDF가 같은 PC에 있으면 그것을 연다).
- 찾는 법
  - 띄어 쓴 말은 **모두 든** 의결서: `자진신고 감경` (같은 쪽이 아니어도 같은 의결서 안에 있으면 됨)
  - 붙어 있는 구절은 따옴표: `"부당한 공동행위" 자진신고`
  - 빼기: `과징금 -입찰`
  - 말의 **앞부분**이 같으면 찾는다(`공동행위` → 공동행위를·공동행위의·공동행위와). 한 글자 말은 뺀다.
  - 사건명·사건번호·의결번호는 띄어쓰기 없이 비교한다(`2019서경`, `2004-313`, 붙여 쓴 옛 사건명도 찾음).
  - 놓치는 경우: 본문에서 다른 말에 **붙여 쓴 가운데**(예: 2000년대 초 의결서의 '부당한공동행위' 속 '공동행위'). 12개 낱말로 원문 전체와 대조했을 때 99.83%를 찾았고, 엉뚱한 의결서가 나온 경우는 없었다.
- 위 칸에서 **위반유형·조치·의결 연도**로 거르고, **최신순 / 많이 나온 순**(찾는 말이 한 쪽에 함께 나온 쪽 수 → 사건명에 있는지 → 나온 쪽 수)으로 정렬한다. 검색어 없이 조건만 골라 목록을 볼 수도 있다. 결과 위의 위반유형 단추(괄호 안 건수)를 누르면 그 유형만 본다.
- 결과마다 의결번호·의결일·대표위반유형·조치와, 찾는 말이 처음 나온 쪽 두 곳의 **앞뒤 문장**이 나온다(목록이 먼저 뜨고 앞뒤 문장은 위에서부터 채워짐).
- 의결서를 누르면: 목록 정보, **원문 PDF 열기**, **공정위 사이트에서 찾기**(사건번호로 거른 공정위 목록 화면), **찾는 말이 나온 쪽** 목록(여러 말이면 어느 말이 나왔는지, 모두 함께 나온 쪽 표시), 그리고 쪽마다 본문(강조 표시, 이전·다음 쪽, 나온 쪽으로 건너뛰기, 쪽 번호로 가기, **인용 복사**).
  - 쪽 번호는 **PDF 쪽 번호**다. 의결서에 인쇄된 쪽 번호와 다를 수 있으니 인용 전에 원문 PDF로 확인한다.
  - 본문은 PDF에서 뽑은 글자라 표·줄바꿈이 원문과 다르게 보일 수 있다.
- **확인 필요** 꼬리표(91건): 공정위 사이트에 올라온 파일 자체의 문제(원문 생략 안내 54, 다른 사건 문서가 붙음 21, 파일 깨짐 12, DRM 2 등). 본문이 그 사건 의결서가 아닐 수 있다.
- 주소창에 검색어·조건·연 의결서·쪽이 담기므로 즐겨찾기로 같은 화면을 다시 열 수 있다.
- **AI 질문**(위 칸의 '낱말 검색 / AI 질문' 중 AI 질문): 의결서에 대해 문장으로 묻는다(예: `입찰담합에서 조사에 협력한 사업자의 과징금 감경은 어떻게 적용했나요?`).
  1. AI가 질문을 의결서 본문에 쓰이는 용어 조합 3~6개로 푼다(위반유형·연도도 짐작).
  2. 이 프로그램이 색인에서 그 말들이 많이 함께 나온 쪽을 고른다(의결서당 최대 3쪽, 모두 최대 20쪽, 비용 없음).
  3. AI가 **그 쪽들만 보고** 답한다. 문장마다 근거 쪽 번호가 붙고, 번호를 누르면 그 쪽 본문이 열린다. 보내지 않은 번호를 달면 지운다(지운 수는 아래에 표시).
  - 오른쪽 위 **AI 답**: 이렇게 이해했습니다, 핵심 답, 사건별 세부, **더 확인할 것**(근거 쪽으로 확인되지 않은 것·더 찾아볼 말), 찾은 말과 건수, 적용 조건, 모델·시간·토큰·대략 비용. 근거 쪽만으로 답이 안 되면 '근거 쪽만으로는 충분히 답하지 못함'이 붙는다.
  - 왼쪽 **근거 쪽** 목록: 번호·사건명·의결번호·쪽·앞뒤 문장. 답에 쓰지 않은 쪽은 흐리게 '답에 안 씀'.
  - 위반유형·조치·연도를 고르면 그 안에서만 찾는다(고르지 않으면 AI 짐작, 짐작한 조건으로 아무것도 없으면 조건 없이 다시 찾음). 조건을 바꿔도 다시 묻지 않는다(비용) — 검색을 다시 누른다.
  - 모델은 세 개: 기본 **GPT-6.1 Sol**(30~55초·약 70원), **GPT-6.1 Terra**(20~35초·약 30원), **Claude Sonnet 5.5**(50~95초·약 100원)(질문당, 입력 약 2.3만 토큰). 11/17 같은 질문 3개를 물어 별도 검토자가 문장마다 근거 쪽과 대조했을 때 Sol이 가장 정확해 기본으로 했다. Claude Haiku 5.5(약 5원)는 각주에 인용된 다른 사건의 판결을 그 사건 판단처럼 쓰는 등 해석 오류가 반복돼 의결서 질문에서는 뺐다(AI 추천에는 남음). 전에 Haiku를 골라 둔 브라우저는 저절로 기본(Sol)으로 바뀐다.
  - **밖으로 나가는 것**: 질문, AI가 만든 찾을 말, 고른 쪽 본문(공개된 의결서)이 고른 AI 회사(Anthropic 또는 OpenAI)로. 공정위로는 아무것도 가지 않는다. 낱말 검색과 달리 질문이 밖으로 나가므로 밖으로 나가면 안 되는 정보는 넣지 않는다.
  - 답은 고른 20쪽 안에서만 만든 요약이라, 그 밖의 의결서에 더 맞는 사례가 있을 수 있다. 인용 전에 근거 쪽과 원문 PDF를 확인한다.
  - 주소로 다시 열면 질문만 채워지고 저절로 묻지는 않는다(비용).

## 7. 오류가 나면

| 화면 표시 | 뜻 | 할 일 |
|---|---|---|
| 인증 오류 | 키가 없거나 틀림·만료 | 2장 확인, 기관 사이트에서 키 상태 확인 |
| 조회 결과 없음 | 그 조건에 자료가 없음 | 기간을 넓히거나 다른 항목·주기 선택 |
| 통계표 없음 | 통계표 코드·ID가 원천에 없음(폐지·변경) | 다시 검색해 새 표를 찾기 |
| 기간 형식 오류 | 시점을 읽을 수 없음(2월 30일, 13월 등) | 시점 형식(4장) 확인 |
| 요청 오류 | 항목·분류 코드가 표와 안 맞음 | 항목을 다시 고르기 |
| 조회 범위 초과 | 한 번에 받을 수 있는 양을 넘음(KOSIS 4만 칸) | 항목·분류·기간 줄이기 |
| 호출 한도 초과 | 기관이 잠시 막음 | KOSIS 1분, ECOS 30분 뒤, OpenDART는 다음 날(하루 약 2만 건) 다시 |
| 원천 서버 오류·연결 실패 | 기관 서버 문제나 네트워크 차단 | 잠시 뒤 다시, 계속되면 인터넷 확인 |

## 8. 지켜야 할 것

- **기관 호출 한도**: KOSIS 1분 200회, ECOS 3분 300회(넘으면 30분 차단), OpenDART 하루 약 2만 건(프로그램은 분당 300회로 제한). 프로그램이 알아서 속도를 늦추지만, 여러 사람이 같은 키로 동시에 많이 받으면 걸릴 수 있다.
- **검색어는 KOSIS로 전송된다**(KOSIS 통합검색을 바로 불러 결과를 보강하기 때문). 밖으로 나가면 안 되는 정보는 검색창에 넣지 않는다. 의결서 탭의 검색어는 밖으로 나가지 않는다.
- 같은 이름의 통계도 기준연도(2015=100, 2020=100)·지역·단위·주기가 다를 수 있다. 서로 다른 표를 이어 붙일 때는 정의를 확인한다.

## 9. 관리

- **검색 색인 새로 만들기**(한 달에 한 번쯤): `python3 -m datahub.build_catalog` (KOSIS 목록 때문에 1시간 안팎, 그동안 같은 키로 다른 조회를 많이 하지 않는다). 일부만: `--only ecos`, `--only kosis`, 항목을 못 받은 ECOS 표만: `--only ecos-missing`.
  - 2026-11-13 색인: KOSIS 통계표 176,630개(주제별 목록 16,000번 호출 상한까지 + 통합검색 보강, 깊은 폴더 8,255개는 아직 남김 — 끝까지 받으려면 `--max-calls` 를 더 크게), ECOS 통계표 617개. 오후에 ECOS를 다시 만들었다.
- **동의어 사전 고치기**: `data/synonyms.csv`를 Excel로 열어 행을 더한다. 열은 `대표어`, `같은말`(같은 통계의 다른 이름, `|`로 구분), `관련어`(함께 볼 만하지만 정의가 다른 말), `메모`. 저장하면 다음 검색부터 반영된다.
- **OpenDART 관련**: 회사 목록 `--only dart`(서버가 일주일마다 알아서 받음), 상장사 업종코드 `--only dart-industry`(15분 안팎), 업종명 표 `--only ksic`(KOSIS 101/DT_1K52E01 전국사업체조사의 제11차 KSIC 분류, `data/ksic_names.csv`. OpenDART 업종코드가 제11차라 제10차 이름을 쓰면 틀림).
- **공공데이터포털 목록**: `--only datago`(목록개방현황 CSV 약 150MB를 받아 색인에 넣음, 1~2분, 한 달에 한 번쯤). 상세 정보는 `data/datago_meta.sqlite`(압축, 약 140MB)에 따로 둔다.
- **시험용 사본으로 켜기**: `DATAHUB_CATALOG_DB=사본경로 python3 -m datahub.server --port 8766` (운영 색인을 건드리지 않음, 다운로드 기록도 사본 옆에 남김).
- 색인이 커서(약 28만 건) 켤 때 메모리를 1GB 가까이 쓴다. 처음 켤 때 화면에 '검색 색인 불러오는 중'이 몇 초~수십 초 보일 수 있다.
- **의결서 색인**(`decisions.sqlite`, 약 311MB, 이 저장소에 없음): 찾는 순서는 환경변수 `DATAHUB_DECISION_DB` → `data/decisions.sqlite`. 파일이 없으면 의결서 탭만 안내가 나오고 나머지는 그대로 된다. 원문 PDF 폴더는 `DATAHUB_DECISION_PDF_DIR`(없으면 공정위 사이트에서 한 건씩 받음).
  - 느린 외장 디스크에서 쓰면 처음 여는 의결서·처음 찾는 말은 몇 초 걸릴 수 있다(흩어진 자리 읽기가 느림, 한 번 읽은 것은 빠름). 내장 디스크에서는 바로 나온다.
- **테스트**: `python3 -m pytest -q tests/` (네트워크 없이 도는 단위 테스트).

## 10. 아직 안 되는 것 (v0.4)

- 관세청·나라장터·오피넷 같은 개별 오픈API 연결(포털 목록 검색·원본 파일 받기까지만 됨; 관세청·조달청은 아직 연결 안 함), 기업집단포털의 소속회사 재무·주주·임원·순환출자·지주회사 자료, 시계열 자동 병합, 사용자 계정.
- DART 재무제표 일괄 파일(zip)은 프로그램으로 받을 수 없어(금감원 사이트가 막음) API로만 받는다. 비상장 외부감사 회사 중 사업보고서를 내지 않는 회사는 재무제표 API에 없다.
- KOSIS 검색 색인은 '국내통계 주제별' 목록 + 통합검색 결과다. 색인에 없는 표도 검색할 때 KOSIS 통합검색으로 바로 찾아 보강한다.
- ECOS 통계표 링크는 ECOS 검색 화면으로 연결된다(ECOS가 표마다 고정 주소를 주지 않음). 통계표 코드로 찾으면 된다.
